# Temporary notes and archive

Agents: put drafts, investigations, proposals, superseded documents and handoffs
here. Name notes `YYYY-MM-DD-short-topic.md`; put the date, status and source
revision near the top. Add each shared note to the appropriate index and to
`docs/file-tree.json` so it can be reached from the project README.

When a decision lands, update the canonical guide and fix history, and mark the
note implemented, superseded or closed. Keep notes that support a FIX entry or
contain unique evidence. Delete scratch notes after checking inbound references
and retaining useful findings. Keep private logs, credentials and disposable
scripts out of the vault.

- [Investigations and run evidence](investigations/README.md)
- [Issue and incident archive](incidents/README.md)
