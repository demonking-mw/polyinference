# Developer guide

Start with contributor onboarding. The architecture guide explains which layer
owns a change; the module guides point to its code and verification. Use the
test guide to choose checks appropriate to the change.

The [illustrated field guide](docs/onboarding.html) is an offline introduction
with the original lecture transcript. Keep its current labels and links accurate
while preserving the transcript as historical evidence.
